# Visual reference mockups

Static HTML mockups of the locked design direction. These are NOT the codebase.
They exist so Claude Code can see the intended look, motion, and layout.

- home-reference.html  — Home page direction (Fraunces locked, cool + lime, loader,
  custom cursor, magnetic CTAs, scroll-velocity, Index/Gallery toggle).
- work-reference.html   — Dedicated /work page (capability filters, reveal-on-scroll,
  app-screenshot visuals with parallax, "View case" cursor).
- home-with-fontswitcher.html — same as home but with a live font switcher, kept for record.

Open in a desktop browser to feel the interactions (they need a mouse).
Rebuild these properly in Next.js + framer-motion + lenis. Do not ship the raw HTML.
